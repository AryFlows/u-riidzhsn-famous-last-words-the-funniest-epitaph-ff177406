One original one-line epitaph, written to `/output/entry.txt`:

> Here lies my to-do list. It outlived me, and it still isn't done.

## Run

```bash
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else (the
default is `/output`). The program refuses to write if the line ever
falls outside the competition's 1–150 character gate, and it prints
the epitaph it wrote so the run can be eyeballed at a glance.
